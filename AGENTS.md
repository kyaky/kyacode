# kyacode

## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature-slug>/` in this repo.

### Triage labels

The five canonical triage roles are used verbatim as label strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`).

### Domain docs

Single-context: one `CONTEXT.md` at the repo root, tracked — it is the
project's vocabulary of record and production comments carry its terms.
Decision records and internal analysis notes are not shipped in this
repository; the load-bearing conclusions live inline in the code comments
that once cited them by path.

Note: per-machine scratch and tooling — `.scratch/`, `.out-of-scope/`,
`research/`, session dirs — are not tracked in git and must not be
committed.
